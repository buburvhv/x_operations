登录 X 账号

账号信息只保存在本机 data 目录，不会上传。密码不保存。

X 经常要求邮箱验证码或两步验证，这时密码登录会失败，请改用「浏览器导入」，一次即可。

  1. 用 Chrome/Edge 打开 x.com 并正常登录
  2. 按 F12 → 顶部「应用 / Application」→ 左侧 Cookie → https://x.com
  3. 找到 auth_token 和 ct0 两行，分别复制「值」粘贴到下面
