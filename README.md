# X Auto Poster — 自动化运营 X（推特）的本地工具

一个跑在本机的网页工具：自动抓取热点，用 AI 写好帖子，你确认后按安全节奏自动发出。只监听 `127.0.0.1`，账号和密钥都留在本机。

调研过程见 [docs/research.md](docs/research.md)。

## 它怎么发帖

发布层用的是 [DezXBT/AgentX](https://github.com/DezXBT/AgentX)（Go 编写的命令行客户端，MIT 协议）：一条命令发一条帖，登录态存在本地 `data/agentx-home`，请求带浏览器请求头和动态 transaction id。

选它是因为官方 X API 的免费档不能发帖（要发帖至少 Basic，约 $100/月），而另一个常见的非官方库 `agent-twitter-client` 在选型时已无人维护。

需要先构建出 `bin/agentx`（Windows 下为 `bin/agentx.exe`）：

```bash
git clone https://github.com/DezXBT/AgentX vendor/AgentX
cd vendor/AgentX && go build -o ../../bin/agentx ./cmd/agentx
```

## 使用

```bash
pip install -r requirements.txt
python -m app.server   # 打开 http://127.0.0.1:8787
```

两种写法，共用同一个发布队列：

- **一键发帖**（默认首页）：选一个热点来源（微博热搜、抖音热榜、知乎热榜、X 全球热搜，或登录后的 X 中文板块），点一次生成一条帖子。后台先挑一个安全且有话可说的热点并定情绪，再从热榜摘要和 X 相关帖里提炼事实、写出几条，最后只留最好的一条。可以用快捷指令或自己的话让 AI 反复修改。
- **选题精写**：自己点一个热点，AI 给 3 种写法，挑一条再改。

灾难伤亡、政治、军事这类事件会被跳过，不拿来蹭热度。小红书热榜需要登录和签名，暂未接入。

排期规则：只在 09:00–23:00 发，每天条数和最小间隔可在后台调（默认每天 3 条、间隔 4 小时），每条额外加 15–40 分钟随机延迟。后台每分钟检查一次，到点发一条，失败不自动重试，错过超过 6 小时就作废不补发。程序需要保持运行。

登录先试账号密码；X 要求邮箱验证码或两步验证时，改用「浏览器导入」（填 `auth_token` 和 `ct0`）。登录后会立刻验证，失败不会保存。

## 后台设置

右上角「后台设置」，或直接打开 http://127.0.0.1:8787/settings ：

- **AI 模型**：任何兼容 OpenAI 接口的服务都能用，地址和模型名可以随意填。写手模型和编辑模型可以分开设（编辑模型负责挑热点和审稿，留空则与写手相同，但两者需是同一个服务商）。
- **发布节奏**：每天 1–5 条，间隔 2–12 小时。
- **写作风格**：填写你的人设和几条自己发过、反响好的帖子，AI 会模仿这个语气。

## 发出去之后

- **数据回收**：每小时回查一次近 14 天已发帖子的浏览、点赞、转发和回复，显示在队列里。
- **爆款复用**：对一条帖子「换个说法再发」，或把它存进写作样本让以后的 AI 模仿。
- **线程**：正文里用空行分段，会按顺序串成一条线程发出。
- **配图**：把文字渲染成一张深色金句图，随帖子一起发。
- **灵感库**：先把看到的好帖子存下来，之后再挑着写。
- **最佳时段**：某个时段的样本积累够之后，排期会优先落在你互动最好的几个小时。

## 文案是怎么写的

提示词在 `app/prompts.py`。写手先从不同角度起草，编辑再按五个维度打分并做最小修改：钩子够不够、有没有信息增量、是否具体、能不能引发回复或转发、像不像人写的。出现编造事实、诱导互动或引战的直接淘汰。

这套规则的依据是 [xai-org/x-algorithm](https://github.com/xai-org/x-algorithm) 公开的排序权重（分享、回复、关注作者的权重远高于点赞，而「不感兴趣」和举报是很大的负分），以及 [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) 里的钩子公式和反 AI 腔清单。

## 风险

这条路线依赖 X 的非官方接口，违反 X 的自动化规则，有封号的可能；X 一改版接口就可能失效，需要跟着维护。所以工具把频率压得很低，也不做自动点赞、关注和回复——这些最容易触发风控，留给你手动做。

新号或长期不用的号，建议先把每天的条数调成 1 条。
